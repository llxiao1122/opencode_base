# Cipher 系统能力清单

共 29 个功能模块（V4.2 清理后净 -8）。审计覆盖 16 个模块/子系统，发现 54 项问题（2 CRITICAL / 1 BLOCKER / 8 HIGH / 16 MEDIUM / 27 LOW）。

> V4.2 清理（2026-07-30）：删除 memory_core.py、memory_server.py、detect/ 整目录（change_detector / event_lifecycle / event_recorder / detector / persistence / feedback_loop），移除 ~3422 行。observation_store.write() 私有化为 _write()。entry.py 精简约 100 行。

### Signal 层路由规则

| 信号组合 | 路由 | 置信度 |
|----------|------|--------|
| 事件关键词 + 时间指示 | event | 0.80 |
| 有时间指示 + 无人名 | task_query | 0.90 |
| 有人名 + 无时间指示 | profile_query | 0.85 |
| 纠错标记 | correction | 0.80 |
| 知识域关键词 + 无人名 | knowledge_retrieve | 0.75 |
| 事件关键词 | event | 0.70 |
| 无信号 | FAISS 兜底 | < 0.50 → event |
